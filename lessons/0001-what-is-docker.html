Docker 是什麼？

Lesson 01 · 閱讀時間約 8 分鐘 · 對應任務：T01 Docker Compose 骨架

為什麼需要 Docker？

你的 cy-stock-dashboard 需要三個服務同時跑：

┌──────────────┐ ┌──────────────┐ ┌──────────────┐ │ Frontend │ │ Backend │ │ PostgreSQL │ │ React + Vite │──▶│ FastAPI │──▶│ Database │ │ port 5173 │ │ port 8000 │ │ port 5432 │ └──────────────┘ └──────────────┘ └──────────────┘

沒有 Docker，你得在自己電腦上手動裝 Node.js、Python、PostgreSQL， 設定版本，確保每台電腦的環境完全一致。Docker 把這些依賴全部 打包進容器，讓三個服務用一條指令啟動： 

docker compose up --build

三個你必須記住的概念

1. Image（映像檔）

Image 是食譜。它描述「這個服務需要什麼環境、安裝什麼套件、 執行什麼指令」。Image 本身不會跑，它是唯讀的模板。

你在 Dockerfile 裡定義如何建立一個 image。

2. Container（容器）

Container 是用食譜做出來的那道菜。它是 image 的執行實例， 是真正在跑的程序。同一個 image 可以同時啟動多個 container。

Container 是隔離的：它有自己的檔案系統、網路、程序空間。

3. Volume（掛載卷）

Container 裡的資料預設在 container 刪除後消失。Volume 是 掛在 container 外面的硬碟，讓資料持久保存。

你的 docker-compose.yml 裡有一行 postgres_data:/var/lib/postgresql/data， 這就是把 PostgreSQL 的資料庫檔案存到 volume，重啟不會遺失。

看懂你專案的 Dockerfile

以 backend 的 Dockerfile 為例：

FROM python:3.12-slim          # 以官方 Python 3.12 image 為基底

WORKDIR /app                   # 在容器裡建立 /app 目錄，後續指令都在這執行

COPY requirements.txt .        # 先只複製 requirements.txt（利用快取加速）
RUN pip install --no-cache-dir -r requirements.txt  # 安裝 Python 套件

COPY . .                       # 再複製所有程式碼進容器

CMD ["uvicorn", "app.main:app", # 容器啟動時執行的預設指令
     "--host", "0.0.0.0", "--port", "8000"]
💡
為什麼先 COPY requirements.txt，再 COPY . .？
Docker 會快取每一層（layer）。如果程式碼有改動但 requirements.txt 沒變， Docker 就跳過重新安裝套件的步驟，大幅加速 rebuild。 這是最常見的 Dockerfile 最佳化技巧。

docker-compose.yml 的角色

Dockerfile 定義「單一服務怎麼建立」，而 docker-compose.yml 定義「多個服務如何一起跑」：誰依賴誰、用哪個 port、共用哪個 volume。 

services:
  db:                          # 服務名稱
    image: postgres:16-alpine  # 直接用公開 image，不需要 Dockerfile
    healthcheck:               # 告訴 Docker 怎麼確認這個服務「健康了」
      test: ["CMD-SHELL", "pg_isready ..."]

  backend:
    build:                     # 從 ./backend/Dockerfile 建立 image
      context: ./backend
    depends_on:
      db:
        condition: service_healthy  # backend 等 db 健康後才啟動
📌
你選取了 pg_isready 這一行。這是 PostgreSQL 內建指令， 用來檢查資料庫是否準備好接受連線。Docker 的 healthcheck 每隔幾秒呼叫它一次， 直到它回傳成功，才讓 backend 啟動。
